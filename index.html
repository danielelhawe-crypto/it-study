Computational Thinking Part 1 & 2 — أساسيات الحاسوب، أنظمة العد، الذاكرة والتخزين، ومكونات الخوارزمية.

1) دورة عمل الحاسوب الأساسية

أي حاسوب — بغض النظر عن نوعه — يقوم بأربع عمليات أساسية فقط، وهذا سؤال مقالي متكرر بذاته:

Input إدخال Processing معالجة Output إخراج Storage تخزين

الحاسوب يتبع Instructions (تعليمات) تُسمى مجموعتها Program. سلسلة الخطوات المنطقية لحل مسألة = Algorithm. اللغة الرسمية المستخدمة لكتابة برامج متعددة = Programming Language.

يأتي سؤال صح/خطأ يقول "المعلومات هي الدرجات الفردية الخام، والبيانات هي العرض المنظَّم..." — هذه العبارة معكوسة عمدًا (بدّلت التعريفين). القاعدة: أي عبارة تصف "الخام" بأنه Information أو "المنظَّم/المفيد" بأنه Data = العبارة خطأ (False) فورًا بدون تفكير إضافي.

طريقة التحويل من ثنائي إلى عشري (أكثر نوع سؤال تطبيقي تكرارًا في محاضرة 1&2):

  1. اكتب أسفل كل رقم قوته لـ2 بدءًا من أقصى اليمين: ...2⁴ 2³ 2² 2¹ 2⁰
  2. اضرب كل رقم ثنائي (0 أو 1) في قوته المقابلة
  3. اجمع النتائج في المواضع التي بها "1" فقط
مثال: 11010
موضع:   1    1    0    1    0
قوة:   2⁴   2³   2²   2¹   2⁰
قيمة:  16    8    0    2    0
المجموع = 16+8+0+2+0 = 26

💡 تدرّب فورًا

بنك الأسئلة يحتوي 9 تمارين تحويل محلولة بالكامل (110→6, 1001→9, 11→3, 111→7, 10011→19, 11010→26, 10001→17, 001101→13, 1111→15) — جربها في تبويب بنك الأسئلة قبل النوم مباشرة، فهي مضمونة الظهور بصياغة مشابهة.

1) بنية أي برنامج C أساسي

#include <stdio.h>      // توجيه معالج مسبق: يُدرج ملف الرأس

int main()               // الدالة الرئيسية، تُرجع Integer
{
      // التعليمات (Statements)
      printf("Hello\n"); // إخراج
      return 0;           // إنهاء الدالة وإعادة التحكم
}
  • #include = توجيه معالج مسبق (Preprocessor Directive)، ويبدأ دائمًا بـ #.
  • stdio.h = Standard Input Output — ملف رأس (Header File) يحتوي تعريفات printf وscanf.
  • main() تُرجع قيمة من نوع Integer دائمًا (int main()).
  • return = الكلمة المفتاحية للخروج من الدالة وتسليم التحكم للمستدعي.

2) مراحل بناء البرنامج (Build Process) — احفظ الترتيب بدقة

المرحلةماذا تفعل
① Preprocessingتنفيذ التوجيهات مثل #include, #define — قبل الترجمة
② Compilingتحويل الكود عالي المستوى (C) إلى Assembly code
③ Assemblingتحويل Assembly code إلى Machine code (بواسطة الـ Assembler)
④ Linkingربط الأجزاء المُترجَمة معًا في ملف تنفيذي واحد

💡 احفظها كسلسلة واحدة

Preprocessing ← Compiling ← Assembling ← Linking. أي سؤال "ماذا يحدث قبل/بعد X" يُحل بترتيب هذه السلسلة فقط.

3) قواعد تسمية المتغيرات (Identifiers) — 3 شروط فقط

  1. لا يبدأ برقم (1id ❌)
  2. لا يحتوي رموزًا خاصة عدا الشرطة السفلية _ (id-1 ❌, id#1 ❌, my num ❌ [بمسافة], $main ❌)
  3. ليس كلمة محجوزة (Keyword) مثل int, float, char, return, volatile...
  • كل الكلمات المحجوزة تُكتب بأحرف صغيرة (lowercase) فقط.
  • C حساسة لحالة الأحرف (Case-sensitive): num وNum متغيران مختلفان تمامًا.
  • الأرقام تُكتب متصلة بدون فواصل آلاف: 100000 صحيحة، 100,000 خطأ.

⚠️ فخ: هل main وtrue كلمات محجوزة؟

main ليست كلمة محجوزة في C! يمكن استخدامها كاسم متغير عادي بلا مشاكل. وبالمثل true ليست كلمة محجوزة في C الأساسية (بخلاف ++C). لا تفترض أن أي كلمة "تبدو" مرتبطة باللغة هي بالضرورة محجوزة — احفظ القائمة الفعلية: int, char, float, double, if, for, while, return, const, volatile, static, struct...

⚠️ فخ %f مقابل %lf

في printf كلاهما (float وdouble) يستخدمان %f. لكن في scanf يجب التفريق: %f لقراءة float، و%lf لقراءة double حصرًا.

9) %d مع متغير char = كود ASCII، وليس الحرف!

char ch = '!';
printf("%d", ch);   // يطبع 33 (كود ASCII للحرف !)
printf("%c", ch);   // يطبع !  (الحرف نفسه)

⚠️ فخ '5' الحرف مقابل 5 الرقم

char ch = '5'; ثم printf("%d", ch); يطبع 53 (كود ASCII للحرف '5')، وليس 5! الحرف '5' بين علامتي اقتباس مفردة مختلف تمامًا عن الرقم الصحيح 5.

وبالعكس تمامًا: int i = 65; printf("%c", i); يطبع الحرف A (لأن 65 هو كود A في ASCII).

10) سلوك scanf مع مدخلات غير متوقعة (مهم جدًا)

  • %c يقرأ حرفًا واحدًا فقط مهما كان طول ما كتبه المستخدم (إدخال "1234" → يقرأ '1' فقط).
  • %d يقرأ الأرقام الصحيحة فقط ويتوقف عند أول رمز غير رقمي (إدخال "1234.4" → يقرأ 1234 فقط ويتجاهل الباقي).
  • %f عند الطباعة تعرض القيمة بـ6 خانات عشرية افتراضيًا دائمًا (حتى لو كانت القيمة الأصلية عددًا صحيحًا: 1234 → 1234.000000).

Arithmetic & Bitwise Operations, Logical & Relational Operators, and Precedence — أكثر محاضرة تحتوي أفخاخًا في كل الفصل.

1) = مقابل == — أخطر فخ في هذا الفصل بأكمله

العاملالاسمالوظيفة
=Assignment (إسناد)يضع القيمة اليمنى داخل المتغير الأيسر
==Equality (مساواة)يقارن قيمتين، ينتج True/False

⚠️ القاعدة الذهبية للإسناد

في أي X = Y، الطرف الأيسر X يجب أن يكون اسم متغير دائمًا (موقع تخزين)، وليس رقمًا ثابتًا. لذلك 100 = grade; خطأ (القيمة على اليسار)، والصحيح grade = 100;. وهذا السؤال بالذات تكرر حرفيًا في 4 امتحانات مختلفة!

2) True و False في لغة C — نقطة دقيقة تم تدقيقها رسميًا

✅ القاعدة الصحيحة (مؤكدة من امتحانات رسمية)

False = 0 فقط حصرًا. لكن True = أي قيمة أخرى غير الصفر (وليست مقصورة على 1 فقط!). العبارة "True تساوي 1 فقط" هي عبارة خاطئة (False) في امتحانات الدكتور الرسمية.

نتيجة العوامل العلائقية (>, <, >=, <=, ==, !=) دائمًا: True أو False (تُمثَّل رقميًا 1 أو 0).

3) العوامل الحسابية والباقي (%) — طريقة الحساب اليدوي السريعة

a % b = باقي قسمة a على b:

  • إذا كان a أصغر من b: الناتج = a نفسه بالكامل (مثال: 10%40 = 10)
  • إذا كان a أكبر: اطرح من a أكبر مضاعف ممكن لـb لا يتجاوزها (مثال: 40%12 → 40-36=4)

⚠️ فخ ترتيب المتغيرات في %

a%b ليس نفس b%a أبدًا! (مثال: a=10,b=40 → a%b=10 لكن b%a=0). اقرأ ترتيب المتغيرين في السؤال بدقة فائقة.

4) أولويات العمليات الحسابية (Operator Precedence)

  1. الأقواس () أولًا دائمًا
  2. * و/ و% — بنفس الأولوية بالضبط، تُحسب من اليسار لليمين
  3. + و- — من اليسار لليمين أخيرًا
مثال: 9 * (4 - 3) % 7 + 5 * 10
الخطوة 1 (الأقواس): 4-3 = 1
الخطوة 2 (من اليسار، * و% بالتساوي): 9*1=9  →  9%7=2  →  5*10=50
الخطوة 3 (+): 2 + 50 = 52

💡 هذا التعبير بالذات تكرر 4 مرات بصيغ مختلفة قليلًا

احفظ الحل خطوة بخطوة كطريقة، وليس الناتج فقط — لأن الامتحانات تُبدّل الأرقام والترتيب قليلًا في كل نسخة.

5) عوامل الزيادة والنقصان (++ و --)

الصيغةالاسمالسلوك
++cPre-increment (سابقة)تُزاد القيمة أولًا، ثم تُستخدم
c++Post-increment (لاحقة)تُستخدم القيمة الحالية أولًا، ثم تُزاد
int c = 5;
printf("%d ", ++c);  // يزيد أولًا (c=6) ثم يطبع 6
printf("%d ", c++);  // يطبع القيمة الحالية 6 أولًا، ثم يزيدها (c=7)
printf("%d ", c);    // يطبع القيمة الحالية 7
// الناتج: 6 6 7

6) العوامل المنطقية (Logical) لدمج الشروط المركّبة

الكلمة الإنجليزيةالعامل
and / و&&
or / أو||
not / ليس!

ترجمة الشروط المركّبة (احفظ الأنماط الثلاثة التالية فهي الأكثر تكرارًا):

الجملةالترجمة الصحيحة
x بين 50 و100(x > 50) && (x < 100)
x تساوي 50 أو 100(x == 50) || (x == 100)
x أكبر من y وأصغر من z(x > y) && (x < z)

⚠️ فخان قاتلان في نفس السؤال

1) لا تكتب سلسلة مقارنات مثل 50 <= x <= 100 — C لا تدعمها منطقيًا؛ افصل الشرطين دائمًا بـ&&.
2) لا تستبدل == (مقارنة) بـ= (إسناد)، ولا &&/|| (منطقية) بـ&/| (بتّية) — أربعة رموز متشابهة الشكل، مختلفة المعنى تمامًا.

7) التقييم القصير (Short-Circuit Evaluation) — قاعدة ثنائية بسيطة

العامليحدث التقييم القصير متى؟
&& (AND)عندما يكون الشرط الأول = False (فالنتيجة False مؤكدة، يتوقف)
|| (OR)عندما يكون الشرط الأول = True (فالنتيجة True مؤكدة، يتوقف)

إذا لم يتحقق شرط التوقف أعلاه، يجب تقييم الشرط الثاني أيضًا (لا تقييم قصير).

💡 طريقة سريعة للحل في الامتحان

احسب فقط قيمة الشرط الأول (True أم False)، وقارنها بالجدول أعلاه مباشرة — لا داعي لحساب الشرط الثاني إطلاقًا لتحديد "هل حدث تقييم قصير أم لا".

8) العوامل البتّية (Bitwise Operators) — تعمل على البتات مباشرة

العاملالاسمالقاعدة
&AND بتّي1 فقط إذا كان كلا البتين = 1
|OR بتّي (Inclusive)1 إذا كان أحد البتين على الأقل = 1
^XOR (Exclusive OR)1 فقط إذا اختلف البتان (أحدهما 1 والآخر 0)
~NOT / المتمميعكس كل بت (0↔1)
<<Left Shiftحذف n بت من اليسار + إضافة n أصفار يمينًا
>>Right Shiftحذف n بت من اليمين + إضافة n أصفار يسارًا
x = 10001001, y = 11001100

~y   = 00110011     (اعكس كل بت)
x&y  = 10001000     (AND: 1 فقط في مواضع الـ1 المشتركة)
x|y  = 11001101     (OR: 1 في أي موضع فيه 1 بأحدهما)
x^y  = 01000101     (XOR: 1 في مواضع الاختلاف فقط)
y<<2 = 00110000     (احذف "11" يسارًا، أضف "00" يمينًا)

⚠️ العوامل البتّية لا تُنتج True/False

بعكس Relational وEquality وLogical، العوامل البتّية تُنتج قيمة عددية جديدة (نتيجة معالجة بتات)، وتعمل فقط على أنواع int أو char (وليس float/double لاختلاف تمثيلهما الثنائي الداخلي).

9) الفخ الثلاثي الأخطر: & أحادي vs && مقابل & ثنائي

الرمزعدد الأطرافالمعنى
